База данных ESP32

Подключите модуль ESP32 через USB для установки или обновления базы данных.

v2.0-DB (Рекомендуемая)
Что нового в v2.0-DB: • Стабильный релиз движка БД
• Оптимизация работы с LittleFS
• Поддержка быстрых индексов
⚠️ Браузер не поддерживает Web Serial. Используйте Chrome, Edge или Brave на ПК.
Плату ESP32 не видно в списке портов? Убедитесь, что используете USB-кабель с поддержкой передачи данных и установлены драйверы CH340 / CP2102.
Зависла прошивка на 0%? Зажмите кнопку BOOT (IO0) на плате в момент нажатия кнопки «Подключить».
